# Port Anything showcases

Compatibility matrices produced with port-anything (this repository): one reference implementation, several candidates, generated test cases, per-feature parity, clustered divergences with minimized repros.

| Directory | Reference | Candidates | Cases |
|---|---|---|---|
| [`coreutils/`](coreutils/) | GNU coreutils 9.12 | uutils 0.12.0 and `main`, busybox 1.38.0, toybox 0.8.15 | 1000 generated per utility (`od`, `nl`, `comm`, `fmt`, `join`, `numfmt`) |
| [`jq/`](jq/) | jq 1.8.2 | jaq 3.1.1, gojq 0.12.19 | 550 from jq's own `tests/jq.test` + 2920 token mutants |
| [`ubuntu-uutils/`](ubuntu-uutils/) | GNU coreutils 9.12 | Ubuntu 26.04's GNU 9.7 and uutils 0.10.0, uutils 0.12.0 and `main` | about 2,000 per utility for 27 utilities, 3 generator seeds |

The story behind the numbers, how the cases were made and what was found: [WRITEUP.md](WRITEUP.md) for `coreutils/` and `jq/`; [`ubuntu-uutils/`](ubuntu-uutils/) has its own write-up in its README.

## Findings (`coreutils/` and `jq/`)

Every finding below was reproduced by hand outside the tool, then checked against the project's issue tracker before being counted as new.

| Project | Finding | Status |
|---|---|---|
| uutils | `numfmt` rejects scientific notation in unselected fields | fixed upstream ([#15312](https://github.com/uutils/coreutils/issues/15312)) |
| uutils | `od -B` rejected | fixed upstream ([#15313](https://github.com/uutils/coreutils/issues/15313)) |
| uutils | `od -S` skips the "cannot skip past end of combined input" check | fixed upstream ([#15314](https://github.com/uutils/coreutils/issues/15314)) |
| uutils | `numfmt` keeps a tab between fields; GNU prints a space | fixed upstream ([#15552](https://github.com/uutils/coreutils/issues/15552)) |
| uutils | `fmt -p`: an unprefixed last line without a newline gets one | fixed upstream ([#15553](https://github.com/uutils/coreutils/issues/15553)) |
| uutils | `od -w1K` accepted, `nl -l <huge>` rejected | fixed upstream ([#15551](https://github.com/uutils/coreutils/issues/15551)) |
| busybox | `od` with mixed type sizes prints the last block's zero padding as input | not reported (busybox takes reports on its mailing list) |
| toybox | `fmt` writes `\e[7m\e[27m` into its output for words with control bytes | fixed in toybox's repository, not released ([#615](https://github.com/landley/toybox/issues/615) still open) |
| jaq | panic instead of a syntax error when a filter ends inside a comment | fixed upstream, released in 3.1.2 ([#476](https://github.com/01mf02/jaq/issues/476)) |
| jaq | `from_entries` ignores `name`/`Name`/`Key`/`Value` | documented by jaq as an incompatibility ([#478](https://github.com/01mf02/jaq/issues/478)) |
| gojq | `isnan` errors on non-numbers (jq returns `false`) | changed to match jq ([#327](https://github.com/itchyny/gojq/issues/327); gojq had chosen this on purpose) |

That's 11 new differences: 9 fixed or changed on the projects' main branches (only jaq's in a release so far), 1 documented, 1 not reported. Not counted: jaq's stack-overflow abort on deeply nested values, reported as [#477](https://github.com/01mf02/jaq/issues/477) but already documented in jaq's README ("Security"), and gojq's `abs` on non-numbers, already fixed on gojq's `main` before these runs. Already tracked upstream (not counted): see the per-directory READMEs.

## Method and caveats (`coreutils/` and `jq/`)

- Linux aarch64 (Ubuntu 25.10 container), every case sandboxed with bubblewrap, no network, with a fixed environment: `LANG=C.UTF-8`, `TZ=UTC`, `SOURCE_DATE_EPOCH=946684800`, and only `PATH` from the host. Hand repros used `LC_ALL=C`. Not yet repeated on x86_64.
- The reference is pinned: GNU coreutils built from the latest release, not the distro package (Ubuntu ships an older GNU, or uutils, which produced false positives in early runs).
- Each directory is a normal port-anything project: `port-anything.yaml`, the committed corpus under `port-anything/recorded/`, `baseline.txt` and `run.txt` (CLI output), and the report (`port-anything-report.html` / `.json`). `versions.txt` records the exact versions, distro and kernel. In `coreutils/`, the CLI specs keep the flags, forms and value types read from GNU's `--help`, without the help text itself.
- busybox and toybox are deliberately minimal. Their numbers measure GNU compatibility, not quality, and options they don't implement currently count as divergences.
